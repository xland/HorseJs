## 目录结构

```shell
├─ HorseJs.exe          # 你可以随意修改此文件的文件名
├─ UI                   # 此目录放置配置文件和HTML/CSS/JS文件，必须叫这个名字
   ├─ css/              # 网页样式目录，只要在UI目录下即可，叫什么名字都可以
   ├─ js/               # 网页脚本目录，只要在UI目录下即可，叫什么名字都可以
   ├─ index.html        # 网页入口文件，只要在UI目录下即可，叫什么名字都可以
   ├─ config.json       # 应用程序配置文件，必须叫这个名字
```
