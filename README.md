## HorseJs

- 使用HTML/JS/CSS创建更快速、更稳定的桌面应用。
- 使用更简单：开发者只在渲染进程内工作。
- 基于WebView2，可执行文件不依赖任何动态链接库且体积小于1M
- 不用适配多个平台，可以做到更小、更快、更易用、能力更大。
